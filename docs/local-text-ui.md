# Local Text UI

I would not dismiss this at all.

In fact, for you, I suspect the TUI version would be delightful:

```text
 Checkbook — Checking                          $4,817.29

 Date       Payee                    Category          Amount
 ─────────────────────────────────────────────────────────────
 08/27/26   Riba Smith               Groceries         -84.17
 08/28/26   Banco General            Transfer        1,000.00
>08/29/26   Felipe Motta             Wine              -36.42

 [a] Add   [e] Edit   [s] Split   [r] Reconcile   [/] Search
```

That's basically Managing Your Money circa 1987.

A terminal is exceptionally well suited to a check register because the fundamental UI is a **sortable table plus a handful of forms**.

And deployment becomes:

```text
checkbook.exe
```
