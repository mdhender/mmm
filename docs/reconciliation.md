# Transaction Reconciliation

## Reconciliation should be a first-class feature

This is where I'd spend UX effort.

Something like:

```text
Reconcile Checking

Statement date:      August 31, 2026
Statement balance:       $4,623.17

Cleared transactions
─────────────────────────────────────

[x] 08/15 Cable & Wireless      -61.22
[x] 08/18 Riba Smith           -112.73
[ ] 08/29 Felipe Motta          -36.42

Cleared balance:          $4,623.17
Statement balance:        $4,623.17
Difference:                    $0.00

                         [ Finish ]
```

A good implementation of that one screen may be worth more than fifty Quicken features.
